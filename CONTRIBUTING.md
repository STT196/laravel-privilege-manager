# Contributing

Thanks for your interest in improving Laravel Privilege Manager.

## Guidelines
- Follow PSR-12 coding style
- Keep changes focused and minimal
- Add or update tests for behavior changes
- Update documentation when behavior changes
- Avoid breaking backward compatibility unless necessary

## Development Setup
1. Install dependencies with `composer install`
2. Run checks with `composer test`
3. Use `setup-check.sh` to validate package layout

## Pull Requests
- Include a clear description of the change
- Mention any security or performance impact
- Reference any related issues
